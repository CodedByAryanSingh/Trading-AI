# Trading AI Frontend

This is a Vite + React + Tailwind frontend scaffold for the Trading-AI project.
It includes a simple candlestick chart component using `lightweight-charts`.

Quick start:

1. cd frontend
2. npm install
3. npm run dev

The dev server will start (default Vite port 5173). The Chart component uses
sample static data; integrate with your backend endpoints to render live data.
